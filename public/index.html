Stop watching gauges. Go sailing.

Endurance isn't another gauge. It's the thing that watches the gauges so you don't have to.

1. Discover your resources

One candidate is selected automatically. With multiple candidates, choose the tank or house bank in Plugin Config. Inputs need timestamped ratios from 0 to 1. A low fuel level and a high holding level both need attention.

2. Confirm settings

Open Server → Plugin Config → Endurance. Enable the resources aboard your boat, select ambiguous source paths, and review reserve and warning ratios. Disable resources you do not carry. Multiple tanks are not automatically combined.

Freshwater can be monitored from level alone. To add a duration estimate, configure an available volume in m³ and a consumption rate, then select the provider's actual units. Battery forecasts and measured duration are optional explicit paths.

Save settings in Plugin Config and return here to verify the assessment.

3. Compare before switching

Preview publishes to environment.endurancePreview. Keep Node-RED operating and compare both assessments. When ready, disable the Node-RED Endurance publishers, then enable live publishing here through Plugin Config. Enable notifications separately.
